Privacy Policy

Last updated: June 2026

QuickPen is a local-first Windows desktop application. It runs entirely on your machine.

1. Local data

User preferences (theme, tool settings, shortcuts, dock position, license state) are stored locally on your device under the Windows user profile.

Screenshots, GIFs and videos created with QuickPen are written to the location you choose at the moment of capture and are never uploaded by the app.

2. Data collection

QuickPen does not include third-party analytics, telemetry or remote logging. It does not require an account to use Free features.

This website does not embed analytics scripts.

3. Updates

The auto-update check downloads a public release manifest from GitHub to compare with the installed version. Only the request to fetch the manifest leaves your machine; no personal data is sent.

4. License activation

If you activate a Pro license, the activation flow only validates the key against the licensing endpoint. License state is stored locally.

5. Contact

For privacy questions, use the channels on the Support page.
