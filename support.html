2. Before opening an issue

  • Confirm you are on the latest stable installer.
  • Include steps to reproduce, expected behavior and what happened.
  • When relevant, include app version, Windows version and monitor/DPI setup.

3. Quick troubleshooting

  • If the radial menu does not open, confirm the double-Ctrl press happens inside 300ms.
  • If a tool stops responding, press Esc to leave the current context and try again.
  • If capture results look empty, retry after disabling Freeze or after restarting QuickPen.
  • If updates fail, reinstall with the latest installer from the releases page.
